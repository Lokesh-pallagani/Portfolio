# Lokesh AIML Portfolio

A cleaned, responsive AIML student + Full Stack Java Developer portfolio.

## Files

- `index.html` — complete portfolio structure
- `style.css` — responsive design, theme styling and animations
- `script.js` — theme switch, mobile menu, reveal animations, active navigation, project filters, modal and contact actions

## Run

No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For VS Code, you can also install **Live Server** and open `index.html` with Live Server.

## Important

The portfolio uses Font Awesome and Google Fonts from CDNs, so internet access improves icon/font loading.

The contact buttons open WhatsApp or the user's default email application; they do not send messages through a server.

Add your own assets later inside `assets/`, including:
- `favicon.png`
- `og-image.jpg`
- `Lokesh-Resume.pdf`
